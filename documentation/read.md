# PFE SACEM Industries

## Description
Application d'analyse et de prévision des ventes et de la production.

## Technologies

- Python
- PostgreSQL
- FastAPI
- Streamlit
- Power BI
- Docker
- XGBoost
- LSTM

## Fonctionnalités

- Analyse des ventes
- Analyse de la production
- Dashboard interactif
- API REST
- Prévisions XGBoost
- Prévisions LSTM
- Réentraînement automatique
- Monitoring système

## Architecture

PostgreSQL → FastAPI → Streamlit → Utilisateur
